🔐 공통·계정 ERD 01 Common

사용자 인증, 역할 관리, 공통 코드, 변경 감사 로그 영역입니다. USER는 모든 행위의 기준이 됩니다.

🎓 학생 관리 ERD 02 Student

학생 기본정보, 학적 변동 이력, 인적사항 수정 요청 관리 영역. 승인 전 원본 데이터는 변경되지 않습니다.

📝 TOPCIT ERD 03 TOPCIT

TOPCIT 시험 회차별 학생 점수 관리. 동일 학생의 동일 회차 중복 등록 불가 (UNIQUE 제약).

erDiagram TOPCIT_ROUND { int round_id PK varchar round_name DATE exam_date int max_score varchar description varchar status } TOPCIT_SCORE { int score_id PK int student_id FK int round_id FK int total_score varchar remark int created_by FK TIMESTAMP created_at TIMESTAMP updated_at } STUDENT { int student_id PK varchar student_no UK varchar user_name } STUDENT ||--o{ TOPCIT_SCORE : "1:N 점수" TOPCIT_ROUND ||--o{ TOPCIT_SCORE : "1:N 회차별"

⭐ 마일리지 ERD 04 Mileage

프로그램 참여·입상에 따른 마일리지 적립/승인/원장 관리. 누적 마일리지는 저장하지 않고 원장 합산으로 산출합니다.

erDiagram PROGRAM { int program_id PK varchar prog_category varchar prog_name DATE prog_date varchar organizer varchar status int created_by FK TIMESTAMP created_at } MILEAGE_POLICY { int policy_id PK int program_id FK varchar participate_type int points varchar description varchar is_use } MILEAGE_APPLY { int apply_id PK int student_id FK int policy_id FK int apply_points int confirmed_points varchar status int approver_id FK TIMESTAMP apply_dt TIMESTAMP approve_dt varchar process_comment } ATTACH_FILE { int file_id PK int apply_id FK varchar file_name varchar file_path int file_size int uploaded_by FK TIMESTAMP upload_dt } MILEAGE_LEDGER { int ledger_id PK int student_id FK int apply_id FK varchar trans_type int points TIMESTAMP trans_dt int created_by FK varchar reason } PROGRAM ||--o{ MILEAGE_POLICY : "1:N 정책" MILEAGE_POLICY ||--o{ MILEAGE_APPLY : "1:N 신청" MILEAGE_APPLY ||--o{ ATTACH_FILE : "1:N 증빙" MILEAGE_APPLY ||--o{ MILEAGE_LEDGER : "1:N 원장"

💰 예산·지출 ERD 05 Budget

사업별 7개 예산항목 한도 관리, 지출 승인, 학생인건비 상세, 예산 변경 이력 관리.
